## Què volem aconseguir?

Els clients de [G1.2](../../guies/g1-2-kea/) ja reben una IP per DHCP. Ara farem que també tinguin Internet a través del servidor.

```text title="El camí dels paquets"
Clients → servidor → Internet
```

- **DHCP** dona als clients la IP, la porta d'enllaç i el DNS.
- **Encaminament** permet al servidor passar paquets d'una targeta a l'altra.
- **NAT** fa que els clients surtin amb la IP externa del servidor. El farem amb `nftables`.

Treballa al **servidor de pràctiques**, que ja ha de tenir Internet. Els clients han de tenir aquest servidor com a porta d'enllaç.

## 1. Identifica les dues targetes

Al servidor:

```bash title="Terminal · servidor"
ip -brief a
```

En aquest exemple:

- **Externa:** `enp1s0`, connectada a `puigcastellar1`, amb IP per DHCP.
- **Interna:** `enp2s0`, connectada a `personal1`, amb IP `192.168.1.1/24`.

**Adapta els noms de les targetes i les IP a la teva activitat.** No canviïs la IP externa a una de fixa.

## 2. Activa l'encaminament

Al servidor, desa aquesta opció i aplica-la:

```bash title="Terminal · servidor"
echo "net.ipv4.ip_forward=1" | sudo tee /etc/sysctl.d/99-encaminament.conf
sudo sysctl --system
cat /proc/sys/net/ipv4/ip_forward
```

L'última ordre ha de mostrar **`1`**: el servidor ja pot encaminar paquets. L'opció es conserva en reiniciar.

## 3. Escriu la configuració de nftables

Obre el fitxer:

```bash title="Terminal · servidor"
sudo nano /etc/nftables.conf
```

Substitueix-ne el contingut pel següent i **adapta `enp1s0` i `enp2s0`**. Aquesta plantilla substitueix les regles de la màquina de pràctiques.

```text title="/etc/nftables.conf"
#!/usr/sbin/nft -f
flush ruleset

table inet filter {
    chain input {
        type filter hook input priority 0;
        policy accept;
    }
    chain forward {
        type filter hook forward priority 0;
        policy drop;

        # Allow clients to reach the external network
        iifname "enp2s0" oifname "enp1s0" accept

        # Allow replies and related traffic back to clients
        iifname "enp1s0" oifname "enp2s0" ct state related,established accept
    }
    chain output {
        type filter hook output priority 0;
        policy accept;
    }
}

table ip nat {
    chain postrouting {
        type nat hook postrouting priority 100;
        # Use the external interface address as the source
        oifname "enp1s0" masquerade
    }
}
```

Queda't amb aquestes tres accions:

- La primera regla de `forward` **deixa sortir els clients**.
- La segona **deixa tornar les respostes** i el trànsit relacionat. `policy drop` bloqueja la resta del trànsit que travessa el servidor.
- `masquerade` **canvia la IP d'origen per la IP externa del servidor**.

`input` i `output` queden oberts per mantenir els serveis del servidor. En aquesta pràctica només filtrem el trànsit que el travessa.

## 4. Valida i carrega les regles

Primer comprova el fitxer:

```bash title="Terminal · servidor"
sudo nft -c -f /etc/nftables.conf
```

**Si no mostra errors**, habilita el servei per a les arrencades i carrega la configuració:

```bash title="Terminal · servidor"
sudo systemctl enable nftables
sudo systemctl restart nftables
sudo nft list ruleset
```

Hi han de sortir les regles, inclosa `masquerade`. Si edites el fitxer més endavant, torna a validar-lo i a reiniciar el servei.

## 5. Comprova-ho des del client

Executa aquestes ordres **al client**, en aquest ordre. Adapta la IP del servidor:

```bash title="Terminal · client"
ip route
ping -c3 192.168.1.1
ping -c3 1.1.1.1
getent hosts www.upc.edu
```

| Comprovació | Què has de veure? |
| --- | --- |
| `ip route` | Una ruta `default via` amb la IP interna del servidor. |
| Ping al servidor | Respostes: el client arriba a la porta d'enllaç. |
| Ping a `1.1.1.1` | Respostes: el client arriba a Internet per IP. |
| `getent hosts www.upc.edu` | Una o més adreces IP: el nom es resol. |

Si una comprovació falla, revisa aquest pas abans de continuar. Si arribes a Internet per IP però no es resol el nom, revisa el DNS que rep el client per DHCP.

## Abans d'acabar

Has de poder explicar:

1. Quina targeta mira als clients i quina a Internet?
2. Per a què hem activat l'encaminament?
3. Què fa `masquerade`?

**Objectiu assolit:** els clients tenen Internet i pots explicar el camí que fan els seus paquets.
